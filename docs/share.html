Show HN: OpenNetAgent – a network agent that cites real sources

Most agents are one model on one machine. OpenNetAgent treats each computer as a node: a coordinator routes tasks over WebSocket, nodes keep local memory/skills, and the coordinator aggregates and verifies.

What works: research with real sources (PubMed, arXiv, Hacker News, Stack Overflow, OpenAlex, Crossref) and [n] citations; document Q&A [Dn]; AST-safe compute; NLI claim verification. Upvoted answers become a knowledge pack that new nodes pull.

Example: GLP-1 mechanism returns 4 real papers in ~11s. Honest limits: Wikipedia/DDG unreachable here; research runs coordinator-side; nodes currently retrieval/echo/NLI.

I stopped letting a small local model invent facts — OpenNetAgent cites sources instead

I tried qwen2.5 0.5B/1.5B for a research agent. It confidently invented “GLP-1 increases orexin release”, which is not in any source. So I changed the design: retrieve from PubMed/arXiv/HN/Stack Overflow/OpenAlex/Crossref, rank sources, extract mechanism sentences, translate, and cite [n]. The local model is optional and never trusted for facts.

Also: document Q&A [Dn], AST-safe compute, NLI verification. Upvoted answers become a knowledge pack; new nodes pull it; later answers cite “network memory”.

把每台电脑变成节点：一个会给出来源的网络智能体

我们习惯把模型越做越大，但一台机器总有上限。OpenNetAgent 换个思路：每台电脑是图上的节点，协调者通过 WebSocket 分发任务，节点保留本地记忆与技能。

它现在能做什么：
- Research：PubMed / arXiv / Hacker News / Stack Overflow / OpenAlex / Crossref，中文证据摘要 + [n] 引用；
- Docs：粘贴报告/代码，按片段回答 [Dn]；
- Compute：AST 安全计算；
- Verify：NLI 判断支持/反驳；
- Evolution：赞/踩 → 经验 → 知识包 → 新节点记忆。

实测：GLP-1 机制返回 4 篇真实论文，约 11 秒；asyncio 报错返回 Stack Overflow 高票答案。
